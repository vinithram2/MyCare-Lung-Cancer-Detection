# 📄 MyCare — Project Documentation, Reports & Presentation

This folder contains all the official academic deliverables for the Major Project **MyCare**:

1. **`MyCare_Complete_Major_Project_Report.docx`**  
   Comprehensive Major Project Phase Report including abstract, literature survey, system design, architectural diagrams, mathematical formulation, experimental results, and conclusion.

2. **`MyCare_IEEE_Transactions_Research_Paper.docx`**  
   Full IEEE Transactions two-column conference/journal research paper formatted with complete methodology, confusion matrices, Grad-CAM comparisons, and formal citations.

3. **`MyCare_16_Page_Weekly_Progress_Report.docx`**  
   Weekly milestone tracker documenting phase-by-phase implementation progress, data preprocessing, model convergence, and system integration.

4. **`MyCare_Lung_Cancer_Detection_Full.pptx`**  
   Complete presentation slides covering problem statement, ResNet-18 residual learning, 99.4% benchmark accuracy, 100% malignant detection, Grad-CAM visual heatmaps, clinical decision support, and live system demonstration.
