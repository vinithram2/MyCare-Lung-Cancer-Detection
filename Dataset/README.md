# 🩻 MyCare — Lung Cancer CT Dataset Repository

This folder contains the benchmark CT scan dataset used for training and evaluating **MyCare AI**.

## 1. Curated Benchmark Test Cohort
* **File:** `Lung_Cancer_Dataset_100_Samples.zip` (49 MB)
* **Contents:** 300 curated axial thoracic CT scan slices:
  - 📁 `Normal/` (100 healthy CT scan slices)
  - 📁 `Benign/` (100 benign solitary pulmonary nodule slices)
  - 📁 `Malignant/` (100 malignant carcinoma slices)
* **Usage:** Unzip and use for instant model testing, evaluation, and drag-and-drop analysis in the web application.

---

## 2. Complete IQ-OTH/NCCD Full Dataset (2,077 Slices)
* **Dataset:** Iraq-Oncology Teaching Hospital / National Center for Cancer Diseases
* **Modality:** Axial Thoracic CT Scans
* **Total Images:** 2,077 CT slices across 3 classes:
  - **Malignant:** 1,346 slices (Adenocarcinoma, Large Cell, Squamous Cell)
  - **Normal:** 631 slices
  - **Benign:** 100 slices
* **Download Full Archive (330 MB):** Available on Kaggle and direct project archives.
